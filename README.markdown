## Introduction
DNK Real Estate is a modern web platform that supports searching, buying, selling, and renting properties in Vietnam. With a user-friendly interface, the project helps users easily interact, from searching for properties to managing their listings.

**Project Status**: 🛠️ In Development (beta version).
**Goal**: 🌟 To simplify real estate transactions, increase transparency, and enhance the user experience.

## Features
- 🔍 **Property Search**: Filter by category (properties for sale, for rent, projects), location, price, and area.
- 📝 **Listing Management**: Property owners can easily create, edit, and delete their listings.
- 🎨 **Intuitive Interface**: The search button is highlighted upon selection, and the design is fully responsive.
- 🛡️ **Admin Panel**: Admins can moderate listings and manage users.
- ⚙️ **API Integration**: Efficiently handles search queries and data storage.

## Usage
1. **🔎 Searching for Properties**:
   - Select a category (Properties for Sale, Properties for Rent, Projects).
   - Enter filters (location, price, area) and click "Search".
   - Save your favorite listings.
2. **🏠 Listing a Property**:
   - Log in as a property owner.
   - Go to "Manage Listings" to create a post with a title, description, and images.
   - Save favorite listings.
   - Communicate with potential clients.
3. **🔧 Administrator**:
   - Log in with an admin account to moderate listings or manage users.
   - Aggregate news about the market.
